## 🧭 [시스템 개요] 오피스 스튜디오 2026이란 무엇인가?

'오피스 스튜디오 2026'은 전통적인 오피스 소프트웨어의 가장 큰 고통이었던 **'시작부터 빈 문서(HWP/Excel/PPT)를 열고 포맷과 서식 맞추기에 시달리는 비효율'**을 원천적으로 종식시킨 차세대 AI 인텔리전트 워크스페이스입니다.

1. **지식 창고 (Knowledge Dock)**: 사내 문서, 회의 녹음, 레거시 양식을 드래그 앤 드롭으로 적재하고 AI의 단일 근거(Grounding Source)로 삼습니다.
2. **3-Way AI 기획 발산 엔진 (Tri-Option Ideator)**: 단일 키워드로부터 정석형, 파격형, 실속형의 3대 맞춤 기획안을 1초 만에 발산하고 캔버스에 자동 주입합니다.
3. **유니버설 스마트 캔버스 (Universal Smart Canvas)**: 공문서, 발표 슬라이드, 스프레드시트, 회의록을 단일 데이터 상태로 동기화 유지합니다.
4. **음성 지원 실시간 코파일럿 독 (Voice Copilot Dock)**: 화면을 보며 마이크 음성 또는 텍스트로 표와 본문을 눈앞에서 실시간 변이(In-Place Mutation)시킵니다.
5. **옴니 출하 서랍 (Omni-Export Drawer)**: HWPX(한컴 2014~2026), 구형 호환 XLSX, 16:9 PPTX, 20mm 여백 PDF 인쇄, 라이프 Hub 연동, 노션 위키 배포를 단일 서랍에서 통제합니다.

## 1. 시스템 핵심 철학: 포맷 프리(Content-First)와 피로도 제로 UX

### 기존 오피스 도구의 치명적 한계
- **포맷 강요의 고통**: 공문서를 쓸지, 슬라이드를 만들지, 엑셀을 채울지 정하지 못하면 단 한 글자도 시작할 수 없었습니다.
- **단일안 강요 피로도**: AI에게 "기획서 써줘"라고 하면 마음에 들지 않는 단 하나의 답변만 나와 프롬프트 수정 루프에 갇혔습니다.
- **서식 깨짐 및 버전 불호환**: 신버전 엑셀 함수(`XLOOKUP` 등)를 썼다가 구형 사내 전산망에서 `#NAME?` 에러가 나거나, 한글 표 서식이 어긋나 야근을 유발했습니다.

### 오피스 스튜디오 2026의 패러다임 전환
```
[기존 레거시 방식]
HWP/엑셀 실행 ➔ 빈 화면 공포 ➔ 서식 줄맞춤 ➔ 내용 작성 ➔ 타 포맷 전환 시 처음부터 복사/재작업

[오피스 스튜디오 2026 골든 패스]
아이디어/출처 적재 ➔ 3-Way 기획안 자동 발산 ➔ 유니버설 캔버스 동적 변이 ➔ 실시간 뷰 전환 ➔ 옴니 출하
```
- **Content-First**: 작성자는 오직 아이디어와 핵심 사실에만 집중합니다.
- **Format-Free**: 텍스트, 수치, 일정이 작성되면 캔버스 상단 탭을 눌러 공문서, 슬라이드, 엑셀, 회의록 형태로 실시간 렌더링을 즉시 전환하여 확인합니다.

## 2. 3-Way AI 기획 발산 엔진 (Tri-Option Ideator)

### 1) 단일 키워드 1초 인큐베이팅 원리
좌측 지식 창고의 소스나 프로젝트 키워드를 기반으로, AI가 기업 환경에 최적화된 **상호 배타적 3대 기획안**을 동시 생성합니다.

| 구분 | 전략 콘셉트 | 예산 및 조직 리스크 | 적합한 상황 |
| :--- | :--- | :--- | :--- |
| **A안 [정석·안정형]** | 사내 기존 규정 100% 준수, 검증된 프로세스 | 보수적 예산 배정, 감사 통과 최우선 | 보수적 임원 보고, 공공 입찰, 감사 대상 업무 |
| **B안 [파격·혁신형]** | 자율 에이전트 및 LLM 전면 도입, 10배 생산성 | 적극적 인프라 투자, 패러다임 시프트 | 미래 먹거리 신사업, 디지털 혁신 TF, 신규 제품 런칭 |
| **C안 [실속·초고속 MVP]** | 4주 이내 초단기 구축, 잔여 예산 100% 맞춤 | 최소 비용, 즉각적인 현업 피드백 확보 | 분기 말 잔여 예산 집행, PoC 시범 사업, 긴급 대응 |

### 2) 소크라테스 핀포인트 2문항 팝업 & 캔버스 자동 파이핑
기획안 카드의 `[ 이 기획안으로 확정 및 캔버스 주입 ]` 클릭 시 소크라테스 핀포인트 질문이 작동합니다:
1. **타깃 심층 정의**: 도입 대상 부서 및 최종 결정권자 지정.
2. **핵심 전달 채널**: 사내 인트라넷, 외부 파트너십 등 채널 지정.
- 응답 완료 시 공문서의 4단계 개조식 조항, 슬라이드의 4장 카드 덱, 스프레드시트의 3개 예산 행과 `=SUM()` 수식에 **데이터가 동시 자동 파이핑(Piping)**됩니다.

## 3. 4대 유니버설 캔버스 & 사내 양식 복제기 (Company Template Injector)

### 1) 4대 전문 문서 실시간 뷰어
- **공문서 / 기안서 (`docs`)**:
  - 상단 표준 3~4단 결재란 (기안자-검토자-협조자-결재자 직인 박스).
  - 행정안전부 공문서 규격 개조식 계층 들여쓰기: `1.` $\rightarrow$ `□` $\rightarrow$ `○` $\rightarrow$ `―`.
  - 본문 최하단 필수 규격 마커: 2타 띄우고 `"  끝."` 자동 보존.
- **발표 슬라이드 (`slides`)**:
  - 16:9 와이드 비율의 카드 슬라이드 덱.
  - 표지, 3단 비교 카드, 핵심 수치 블록 레이아웃.
- **스프레드시트 (`sheets`)**:
  - 1997년 이후 전 버전(Excel 97~365, 구형 한셀) 100% 호환 불변 표준 수식(`=SUM()`, `=AVERAGE()`) 전용 바인딩.
  - 신규 함수 배제로 구형 사내망 수식 깨짐 원천 차단.
- **회의록 및 할 일 (`minutes`)**:
  - 일시, 장소, 참석자, 안건 메타데이터.
  - STT 기반 핵심 논의 사항 및 실행 과제(Action Items) 체크리스트.

### 2) 사내 고유 서식 주입기 (Company Template Injector)
- **사용법**:
  1. 좌측 지식 창고에 사내에서 실제 사용하는 HWP, PDF, XLSX 양식 파일을 업로드합니다.
  2. 파일 항목 우측의 `[ 사내 양식으로 적용 ]` 칩을 클릭합니다.
  3. 사내 고유 결재선 직책(팀장-실장-본부장-대표이사), 문서 여백, 표 테두리 스타일이 인식되어 캔버스 본문에 즉시 복제 주입됩니다.

## 4. 🎙️ 음성(STT) 지원 실시간 대화형 코파일럿 독

### 1) 우측 상시 도킹 패널 인터페이스
화면 상단 `[ AI 코파일럿 ]` 버튼으로 언제든지 열고 닫을 수 있는 구글 워크스페이스 Gemini 사이드 패널 형태의 지능형 작업대입니다.

### 2) Web Speech API 기반 원클릭 음성 명령 (STT)
- 입력창 좌측의 `<Mic />` 버튼을 클릭하면 브라우저 내장 Web Speech API가 구동됩니다.
- 음성 인식 중에는 붉은색 펄스(Pulse) 애니메이션이 작동하며, 사용자가 말하는 한국어가 인풋창에 실시간 타이핑됩니다.

### 3) 인플레이스 상태 변이 (In-Place Mutation) 실전 프롬프트 예시

| 목적 | 음성/텍스트 프롬프트 예시 | 시스템 실시간 반응 |
| :--- | :--- | :--- |
| **표 행 추가** | "3행에 클라우드 서버 비용 120만원 추가해줘" | 스프레드시트에 행 즉시 삽입, 총 합계 `=SUM(D2:D5)` 자동 재계산 |
| **공문서 어조 변환** | "공문서 개조식 어조로 변환해줘" | 모든 서술어를 `~추진함.`, `~보고함.`, `~검토함.`으로 일괄 치환 |
| **비즈니스 정중체** | "임원 보고용 정중체로 바꿔줘" | 서술어를 `~바랍니다.`, `~보고드립니다.`로 품격 있게 일괄 변환 |
| **수식 재검증** | "예산 합계 수식 다시 계산해줘" | 표 데이터 전수 스캔 후 최하단 합계 행 수식 무결성 바인딩 |
| **3줄 서머리** | "핵심 내용 3줄로 요약해줘" | 조항 개수, 총 예산 금액, 결재선 정보를 바탕으로 3개 불릿 요약 생성 |

### 4) 실수 방지용 무손실 되돌리기 (Undo) 안전망
- 코파일럿의 모든 변이 액션은 히스토리 스택에 타임스탬프와 함께 자동 기록됩니다.
- 상단 또는 코파일럿 헤더의 `[ ⏪ 되돌리기 (Undo) ]`를 클릭하면 방금 전 상태로 완벽히 롤백됩니다.

## 5. 🎨 NotebookLM 스타일 [인포그래픽 스튜디오]

상단 우측의 보라색 버튼 `[ 인포그래픽 스튜디오 ]`를 클릭하면 현재 캔버스 본문의 복잡한 텍스트와 숫자가 4대 비주얼 인포그래픽 카드로 1초 만에 렌더링됩니다.

### 4대 인포그래픽 비주얼 템플릿
1. **🍱 벤토 그리드 요약 (Bento Grid)**: 실리콘밸리 트렌드의 다분할 박스형 레이아웃으로 타깃, 추진 콘셉트, 예산 규모, 컴플라이언스 통과 현황을 한눈에 조망.
2. **🗺️ 추진 로드맵 (Roadmap)**: 기안 ➔ 인프라 셋업 ➔ 시범 파일럿 ➔ 전사 확대로 이어지는 4단계 타임라인 마일스톤 플로우.
3. **📈 KPI 지표 대시보드 (KPI Dashboard)**: "78% 공수 절감", "100% 표준화율" 등 핵심 성과를 대형 타이포그래피와 프로그레스 바(Bar)로 강조.
4. **⚖️ 3-Way 비교 매트릭스 (Comparison)**: A안(정석), B안(파격), C안(실속)의 장단점과 전략적 권고사항을 3열로 대조.

### 출력 및 이미지 저장 가이드
- **인포그래픽 이미지(PNG) 다운로드**: HTML5 Canvas 고해상도(1200x700) 렌더러가 작동하여 프레젠테이션 및 보고서 삽입용 고화질 PNG 파일을 즉시 생성합니다.
- **PDF에 포함하여 출력**: 인쇄 표준 스타일을 적용하여 즉시 종이 또는 PDF 문서로 인쇄합니다.

## 6. 🚀 옴니 출하 서랍 & 다중 포맷 실시간 라이브 미리보기

상단 우측 `[ 최종 저장 및 출하 ]` 클릭 시 우측에서 400px 너비의 슬라이드 서랍이 부드럽게 등장합니다.

### 1) 사전 비행 안전 검수 패널
출하 직전 0.3초 백그라운드 스캔을 통해 " 끝." 마커 구비 여부, 휴대폰 번호 마스킹 상태를 점검하여 100점 만점 지표와 함께 합격 뱃지를 발행합니다.

### 2) 버전 호환 4대 파일 컴파일러 다운로드 센터
- **한컴 공문서 (`.hwpx`)**: 국가 표준 KS X 6101 OWPML XML 컨테이너로 컴파일. 한컴 2014, 2018, 2020, 2022, 2024, 2026 전 버전에서 완벽한 레이아웃 보장.
- **스프레드시트 (`.xlsx` / `.csv`)**:
  - `.xlsx`: Excel 97부터 365까지 호환되는 불변 수식 바인딩 통합 문서.
  - `.csv`: 구형 사내 전산망 및 레거시 ERP 전용 UTF-8 BOM(`\uFEFF`) 탑재 텍스트 파일.
- **발표 슬라이드 (`.pptx`)**: 16:9 와이드 카드 슬라이드 덱 다운로드.
- **PDF 문서 및 A4 종이 인쇄**:
  - `@media print` 20mm 표준 여백 전용 스타일을 적용하여 툴바와 패널은 숨기고 순수 본문 캔버스만 정확히 출력.

### 3) 사내 결재망 1초 서식 복사기 (Smart Clipboard Injector)
- **배경**: 구형 ActiveX 인트라넷이나 2010 이전 한글을 쓰는 부서/거래처를 위한 필수 안전장치.
- **동작**: `navigator.clipboard.write` 표준 API를 통해 서식 있는 HTML Table과 플레인 텍스트를 클립보드에 동시 복사.
- **결과**: 사용자가 사내 결재 본문창이나 구형 한글에 `Ctrl + V` 하면 결재선 표, 메타정보 표, 개조식 들여쓰기가 깨짐 없이 원형 그대로 복제됩니다.

## 7. 세컨드 브레인 OS 에코시스템 직결 (라이프 Hub & 노션 연동)

### 1) ⚡ 할일 ➔ 라이프 Hub [Tasks DB] 직결 파이프라인
- 문서 본문에서 `~수립`, `~작성`, `~검증`, `~보고` 등 동사형 종결 과제를 자동 파싱합니다.
- 담당자, 마감일, 우선순위(`P0`/`P1`/`P2`)를 확인 후 **[ 라이프 Hub에 즉시 등록 ]**을 누르면 제2챕터 [라이프 Hub]의 마스터 저장소로 실시간 주입됩니다.
- "3건의 과제가 라이프 Hub로 전송되었습니다. [라이프 Hub로 이동]" 토스트를 통해 즉시 내비게이션됩니다.

### 2) ☁️ 노션 Wiki 클라우드 배포
- 공문서와 기획서 본문 데이터를 노션 네이티브 블록(Heading, Callout, Table, Bullets, Quote)으로 파싱합니다.
- 원클릭 노션 마크다운 복사 및 노션 API를 통한 [Office Docs Wiki] 마스터 DB 자동 적재를 지원합니다.

### 3) 🎧 2분 오디오 브리핑 플레이어
- 전문 앵커 2인의 대화형 팟캐스트 포맷으로 문서의 핵심을 2분 만에 요약 브리핑합니다.
- 출퇴근길, 회의 직전 엘리베이터 안에서 스마트폰으로 빠르게 문서 요지를 파악할 수 있습니다.

## 8. 사전 비행 안전 검수기 (Pre-flight Quality Gate) & 보안 정책

### 1) 3중 컴플라이언스 품질 게이트
1. **공문서 서식 규격 점검**: 본문 마지막 항목 작성 후 반드시 2타 띄우고 `"  끝."`으로 종결되었는지 확인.
2. **개인정보 비식별화 점검**: 본문 내 휴대전화 번호(`010-XXXX-XXXX`) 패턴 발견 시 마스킹(`010-****-XXXX`) 제안.
3. **수식 및 결재선 무결성**: 3단 이상 결재선 직책 구성과 `=SUM()` 수식 유효성 보증.

### 2) 사내 기밀 보안 정책 (Zero Data Leak)
- **클라이언트 사이드 메모리 컴파일**:
  - HWPX, XLSX, PPTX, CSV 생성은 외부 서버를 거치지 않고 사용자 브라우저 메모리 상에서 JSZip 및 XML 엔진으로 즉시 컴파일됩니다.
  - 사내 대외비 문서 및 예산 내역이 외부 서버로 유출될 위험이 0%로 완벽히 차단됩니다.
