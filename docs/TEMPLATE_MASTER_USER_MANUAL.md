## 🧭 [시스템 개요] 템플릿 마스터란 무엇인가?

'템플릿 마스터'는 노션 워크스페이스를 만들 때 겪는 **"빈 백지 상태의 막막함, 데이터베이스 속성 설정의 번거로움, 복잡한 수식과 관계형 연결의 진입장벽"**을 완전히 없애주는 **AI 템플릿 설계 공작소(Builder Studio)**입니다.

- **자연어/음성 인터페이스**: "유튜브 콘텐츠 제작 관리 파이프라인 만들어줘", "고객 상담 CRM과 견적서 연결해줘"라고 말만 하면 끝납니다.
- **RDBMS 구조화 엔진**: 단일 표를 만드는 것이 아니라, 여러 DB 간의 1:N / N:M 양방향 관계형(Mutual Relation)을 자동으로 엮어냅니다.
- **Formulas 2.0 수식 자동 작성**: 진척률 게이지 바(`■■■■□`), D-Day 카운트다운(`⏳ D-4`), `map()`/`filter()` 복합 수식을 자동으로 생성합니다.
- **노션 원클릭 배포**: 웹에서 설계된 결과를 클릭 한 번으로 실제 노션 계정에 접이식 토글 가이드와 함께 배포합니다.

## 🖥️ PART 1. 템플릿 마스터 웹 공작소 조작법

### 1. 프롬프트 입력 및 멀티모달 캡처
1. **자연어 프롬프트 입력**:
   - 텍스트 입력창에 원하는 업무나 비즈니스 워크플로우를 자유롭게 설명합니다.
   - *입력 예시*: "프리랜서 디자이너를 위한 프로젝트 및 클라이언트 정산 관리 DB를 설계해줘."
2. **음성 녹음 (🎙️ STT)**:
   - 마이크 버튼을 누르고 말하면 실시간으로 텍스트로 변환되어 프롬프트로 들어갑니다.
3. **참고 자료/파일 첨부 (📎)**:
   - 기존에 사용하던 엑셀/CSV 양식이나 메모 스크린샷을 첨부하면 AI가 구조를 파싱하여 노션 DB 속성으로 매핑합니다.

### 2. 4단계 지능형 생성 파이프라인 (The 4-Step Pipeline)
- **1단계 (니치 도메인 분석)**: 사용자의 요청에서 핵심 업무 흐름과 페인포인트를 진단합니다.
- **2단계 (정보 구조 IA 설계)**: 필요한 데이터베이스 목록과 대시보드 위젯 맵을 도출합니다.
- **3단계 (스키마 & 릴레이션 엔지니어링)**: 각 DB별 속성 타입(Select, Date, Formula 등)과 관계형 링크를 정의합니다.
- **4단계 (더미 데이터 주입 & 검증)**: 즉시 테스트해볼 수 있는 3~5건의 실전 시드 데이터를 주입합니다.

### 3. 실시간 인터랙티브 캔버스 조작
- **속성 추가/삭제**: AI가 생성한 DB 스키마 카드를 보며 불필요한 속성은 마우스로 삭제하거나 새 속성을 추가합니다.
- **버전 관리 및 되돌리기 (Undo/Redo)**: 설계 수정 중 이전 상태로 돌아가고 싶을 때 상단 `[ ⏪ 되돌리기 ]` 버튼을 누릅니다.
- **[ 💾 저장 및 관리 ]**: 설계된 템플릿 구조를 내 보관함에 JSON 형식으로 영구 백업합니다.

## ⚙️ PART 2. 스키마 설계 및 Formulas 2.0 수식 엔진 원리

### 1. 5~7개 최적 속성 원칙 (Minimalist SSOT)
- 속성이 10개를 넘어가면 실무자가 관리를 포기하게 됩니다. 템플릿 마스터는 핵심 5~7개 속성으로 압축 설계합니다.

### 2. Formulas 2.0 수식 자동 빌드 규칙
- **진척률 시각화**: `let(p, round(prop("완료 과제 수") / prop("전체 과제 수") * 100), ...)` 형태의 자동 비주얼 게이지 바를 생성합니다.
- **스마트 D-Day**: 마감일이 지났는지, 오늘인지, 며칠 남았는지를 `dateBetween()` 수식으로 연산하여 `🔥 오늘 마감`, `⏳ D-3`, `✅ 완료` 뱃지를 표시합니다.
- **Null-Safety 예외 방어**: 날짜가 비어 있을 때 오류(Error)가 나지 않도록 `empty(prop("목표일"))` 예외 구문이 자동 삽입됩니다.

## 🚀 PART 3. 노션 원클릭 무손실 배포 (Export Engine)

### 1. 배포 프로세스
1. 상단 우측 `[ ⚡ 노션 내보내기 ]` 버튼을 클릭합니다.
2. 백그라운드 배포 엔진이 노션 API를 호출하여 **2-Pass 순차 생성 방식**으로 배포합니다:
   - **Pass 1**: 부모 페이지 및 모든 마스터 DB 뼈대 일괄 생성.
   - **Pass 2**: DB 간 양방향 관계형(Relation) 속성 및 수식(Formula) 연결.
3. 배포 완료 토스트와 함께 `[ 🔗 생성된 노션 페이지 바로가기 ]` 링크가 팝업됩니다.

### 2. 최상단 접이식 토글(Toggle) 가이드
생성된 노션 페이지 맨 위에는 항상 다음 토글 블록이 자동으로 포함됩니다:
- `▶ 💡 [1초 세팅 가이드 & 2026 노션 자율 에이전트 지침서]`
- 사용자가 토글을 열면:
  1. 칸반 보드 / 캘린더 뷰 10초 세팅법
  2. 노션 커스텀 AI 에이전트에 붙여넣을 시스템 프롬프트(RISEN 규격)가 완비되어 있습니다.

## ❓ PART 4. 자주 묻는 질문 (FAQ)

### Q1. 노션으로 내보냈는데 관계형 속성이 비어있거나 안 보입니다.
- **해결**: 노션 API의 양방향 릴레이션 반영에 2~3초 지연이 발생할 수 있습니다. 노션 페이지를 `F5`로 새로고침하면 정상 표시됩니다.

### Q2. 수식 결과에 빨간색 에러 느낌표가 뜰 때는 어떻게 하나요?
- **해결**: 연결된 날짜 속성이 완전히 비어있을 때 발생할 수 있습니다. 날짜를 한 번 입력해 주거나, 템플릿 마스터에서 '빈 값 방어 수식'을 적용하여 재배포하시면 해결됩니다.
